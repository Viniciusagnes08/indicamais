# Indica+ ST1 - Liga de Vendas

MVP interno de gamificação comercial da ST1 Internet.

## Regras atuais

- Venda confirmada: 100 pontos.
- Indicação sem venda: 0 pontos.
- Desempates: MRR, conversão e venda mais recente.
- Meta global demonstrativa: 20 vendas no mês.

## Dados

A versão publicada usa uma base demonstrativa calibrada em 10 vendas, R$ 930 de MRR e 48 indicações válidas. Não contém dados pessoais de clientes.

## Mapa

Leaflet 1.9.4 com tiles do OpenStreetMap. A visualização agrega vendas por município na região de São Luís.

## Próxima integração

Substituir os arrays locais por um endpoint autenticado que leia as vendas confirmadas e o indicante estruturado no Kommo/GrowthPack.
